# RoadVision AI

Mobile-first browser camera prototype for experimenting with road computer vision.

## V1

- Live phone/webcam access using `getUserMedia`
- Prefers rear camera on mobile
- Front/rear camera switching
- Live resolution and render FPS telemetry
- Fullscreen control
- Mobile-first interface
- No video upload or storage
- Canvas overlay reserved for future computer-vision detections

## Run

Camera access requires a secure context. Deploy through GitHub Pages (HTTPS) or run on localhost during development.
